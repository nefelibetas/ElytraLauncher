# Elytra Launcher v1.2.0

本次更新集中在依赖解析、地图预览、下载与前端启动性能。

## 亮点

### 依赖解析

- Mod 依赖冲突检测；同一依赖链内版本不一致时提示并支持自动重选。
- 依赖名称、版本列表、项目详情与搜索结果增加进程内 TTL 缓存，重复打开弹窗明显减少网络请求。

### 世界预览

- 世界地图瓦片改为后端 LOD 渲染，缩放查看大范围区域更流畅。
- 群系最近邻按 region 距离剪枝，群系检索与地图渲染减少重复扫描。
- 地图瓦片缓存改为分片存储与分片淘汰，控制缓存体积并降低大目录扫描成本。

### 下载与启动

- 分段下载改为工作块窃取，慢连接不再拖住其余工作块。
- 下载 worker 数按 host 单流吞吐自适应，减少不必要的高并发。
- 版本列表与 JDK 探测增加缓存，启动页刷新更快。
- 下载进度 ETA 按时间常数平滑，速度显示更稳定。

### 皮肤与界面

- 全身皮肤预览改用 WebGL MSAA。
- 皮肤绘画器 3D 直绘改用 WebGL 面 ID 拾取，指针悬停/落笔更跟手；WebGL 不可用时自动回退软件路径。
- 皮肤、地图、种子地图等重工具与顶级 Tab 改为按需加载，首屏不再预加载未访问页面。
- 修复皮肤 3D 预览首帧空白与部分斜视面块消失。

### 构建

- 跨平台 clang-cl 查找与 `cc::Build` 工具链指定修正，改善 Windows/macOS/Linux 构建一致性。

## 下载

Release 产物包含 Windows（便携 zip / NSIS / MSI）、macOS（universal dmg）与 Linux（AppImage / deb / rpm / 便携 tar.gz）。

随仓库分发的第三方内容与数据见 [THIRD-PARTY-NOTICES.md](https://github.com/nefelibetas/ElytraLauncher/blob/main/THIRD-PARTY-NOTICES.md)。
